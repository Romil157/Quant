# AegisQuant Research Notebooks

This directory contains interactive Jupyter research notebooks for:
- Exploratory data analysis (EDA) and microstructure analysis.
- Alpha signal formulation, decay analysis, and Information Coefficient (IC) evaluation.
- Walk-forward strategy optimization, cross-validation, and parameter sensitivity surfaces.
- Portfolio construction comparisons (Equal-Weight vs Risk Parity vs Minimum Variance vs Mean-Variance).
